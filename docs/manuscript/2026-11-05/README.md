## 格式与来源

- `.md` 为阅读和编辑入口；`.ima.json` 保存同步编辑的富文本正文，保存标题、强调、代码、表格、链接和图片；原始布局属性见原始来源。
- `.ima.raw.json` 为取回时的原始来源。9.6、9.7 使用 `ima-source-bundle-v1` 对象，在 `sources[].content` 中逐字保留主稿和补充笔记的原始 JSON 字符串；其他笔记仍为原始 JSON 数组。
- `manifest.json` 保存来源笔记 ID、来源修改时间、取回时间、合并记录及当前文件 SHA-256。来源修改时间与本地编辑时间分别记录。

当前书稿以本目录整理后的正文为基准。再次从 IMA 取稿时应使用新的日期目录，避免覆盖已有编辑。

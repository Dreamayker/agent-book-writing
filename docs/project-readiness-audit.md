# Agent 图书编写项目审查与整改记录

> 审查日期：2026-10-19  
> 审查对象：本仓库、`wallet-review-lab` 实验工程和第 9 章稿件

## 结论

项目已经满足“技术审校稿 + 配套实验工程”的要求，尚未满足“可出版定稿”。第 9 章核心案例覆盖完整，但不能宣称覆盖所有代码评审场景。当前范围覆盖低风险变更、金额精度、对象级授权、并发双花、幂等重试、依赖漏洞、提示注入，以及风险路由、Finding Schema、证据门禁、去重、仲裁和人工升级。

## 已确认的出版缺口

1. 案例驱动正文约 9,600 字符，距离调整后的 45,000～55,000 中文字符目标较远。
2. 尚无真实模型的双模型、每案例 3～5 次重复实验，因此不能宣称真实 Precision、Recall、成本、延迟或稳定性。
3. 真实实验图表、案例截图、最终出版编辑和引用格式适配尚未完成。
4. 原有评分器主要按 Finding ID 集合计算，尚未完整评价位置、证据充分性、严重性、修复可行性和跨案例泛化。

## 场景边界

暂未覆盖的通用评审场景包括 SQL/命令/模板注入、SSRF、密钥和个人数据泄露、认证与会话安全、数据库迁移回滚、API 兼容性、超时与资源耗尽、消息重复和最终一致性、性能退化、可观测性与审计完整性、CI 发布链路权限以及真实多仓库影响分析。这些是后续扩展项，不应在本章中暗示已经覆盖。

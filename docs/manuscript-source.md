## 格式与追溯

- `.md`：阅读与编辑入口，保留标题、强调、列表、表格、代码、链接和图片引用。
- `.ima.json`：与 Markdown 同步编辑的富文本正文，保留原始节点的样式、表格单元格和布局属性。
- `.ima.raw.json`：取回时的来源记录。9.6、9.7 为 `ima-source-bundle-v1` 对象，`sources[].content` 逐字保存主稿与补充笔记的原始 JSON 字符串，并附来源笔记 ID、时间和 SHA-256；其他笔记仍为原始 JSON 数组。
- `manifest.json`：当前文档列表、来源元数据、合并记录、编辑状态，以及 Markdown、富文本正文、原始来源文件的 SHA-256。原始来源记录与整理后正文用途不同。

重新渲染 Markdown 可运行 `node scripts/export_ima_notes.mjs 2026-11-05 --from-local`。再次从云端导出应使用新日期目录，导出脚本会拒绝覆盖已标记为编辑状态的当前书稿。

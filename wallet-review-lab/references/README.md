# 事实核验资料

`source-audit.csv` 是第 9 章外部事实与数据的唯一核验入口。正文中的精确数字、产品能力、模型名称、论文结论和“行业共识”类强表述，必须在表中达到 `verified` 状态才能作为事实保留。

## 状态

当前 22 条原稿声明已全部完成新稿处置决策，没有 `pending` 项。`local-eval` 项等待真实模型实验，不属于外部来源遗留。

- `verified`：已核对原始论文、官方文档或原始数据，并确认表述边界。
- `pending`：已识别声明，但尚未取得足够的一手来源。
- `rewrite`：原表述过强、概念不准确或无法由现有来源支撑，应先改写。
- `remove`：名称错误、数据不可追溯或不适合进入正式书稿。
- `local-eval`：应由本项目真实实验产生，不采用厂商数据替代。

## 规则

1. 优先原始论文、官方文档和原始数据集。
2. 厂商案例只能标注为“厂商披露”，不能写成行业普遍结论。
3. Precision、Recall、采纳率和解决率不能混用。
4. GitHub 项目引用记录仓库、commit/release 和访问日期。
5. 易变化的价格、模型名和产品功能必须注明“截至日期”。
6. 本项目的录制回放数据不能作为真实模型能力证据。

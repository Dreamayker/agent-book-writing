## 3. 实现一致性修正

1. 明确目标架构与当前 MVP 的边界：当前 `ReviewPipeline` 不直接调度 pytest、Semgrep 和 OSV。
2. PR-04 的根因位置修正为 `app/repository.py` 的 `atomic` 锁移除，不再错指 `app/service.py`。
3. 高风险仲裁结果修正为代码中的 `escalate`。
4. 语义标签名修正为策略中的 `credentials`，并说明当前由案例显式提供。
5. 明确 `deterministic-only` 是实验对照组，尚未封装成当前的 `ReviewMode`。
6. 增加 PR 摘要与影响分析方法，但不声称已实现跨仓库分析。

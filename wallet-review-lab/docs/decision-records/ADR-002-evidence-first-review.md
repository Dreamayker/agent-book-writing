# ADR-002：采用证据优先的评审与仲裁机制

- 状态：已采纳
- 日期：2026-08-16

## 背景

多个 Agent 可能重复报告同一问题，也可能共享同一错误假设。简单多数投票会把相关性错误误认为独立共识。自然语言置信度也无法代替可复现事实。

## 决策

- 所有发现使用统一 Finding Schema。
- 阻断 Finding 必须包含文件定位和至少一项证据。
- 编译、失败测试、静态分析和依赖扫描优先于无证据自然语言判断。
- 同一 `finding_id + file` 的发现合并，而不是重复计票。
- 仲裁合并来源和证据，不允许凭模型数量覆盖确定性结果。
- 涉及金额、授权、凭证或数据库事务时强制人工终审。

## 后果

积极影响：结论可审计、可复现，能够统计重复率并降低幻觉传播。

代价与限制：需要维护 Finding ID、工具证据映射和标准答案；部分架构与业务问题无法由确定性工具证明，仍需保留 Concern 和人工判断路径。

# PR-07：兼容旧版 HTTP 客户端

## 需求

为复现一个旧系统兼容问题，将教学依赖审计清单中的 `requests` 版本调整为 `2.19.1`。

## 验收标准

- 依赖变更必须通过漏洞数据库扫描。
- 已知漏洞必须给出公告 ID、影响范围、修复版本和适用条件。
- 相同根因的 CVE、GHSA 和 PYSEC 别名不能重复计为多个独立缺陷。
- 教学审计依赖不得进入应用运行环境。

## 待审查变更的预设缺陷

`requests 2.19.1` 命中多个 OSV 公告。其中 `GHSA-x84v-xcm2-53pg / CVE-2018-18074` 为 HIGH，影响认证头在特定 HTTPS 到 HTTP 重定向场景下的泄露，最低修复版本为 `2.20.0`。本案例统一修复到当前审计基线 `2.33.0`。
